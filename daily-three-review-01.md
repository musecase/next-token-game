First-pass bank: **90 days / 270 puzzles**. These are deliberately not exhaustively play-tested.

Review marks:

- `[x]` plausible enough
- `[ ]` leave blank if you are unsure
- Add `REPLACE` or a note beside anything that feels impossible, dull, repetitive, or factually wrong

Each target is intended to be an exact single token for the local Qwen model. The three columns are a loose difficulty mix, not a promise.
